Executive Summary
Titun Music Market is a scalable, cloud-hosted web application designed for digital media distribution, e-commerce, and direct-to-consumer artist engagements. The project involved end-to-end architecture design, fullstack application logic development, automated Git deployment pipelines, web server hardening, and cloud security posture management.

Detailed Technical Contributions & Architecture
1. 💻 Fullstack Software Engineering
•	Modular View Engine Architecture: Designed and implemented reusable view partials (e.g., views/partials/whatsapp-float.ejs) to optimize UI reusability, maintainability, and clean DOM rendering across the site.
•	Database & Dynamic Content Routing: Built backend routes and data access layers to dynamically serve audio previews, metadata, digital assets, and customer interactions without latency overhead.
•	Responsive Frontend Interactivity: Standardized UI/UX cross-device compatibility, ensuring optimal mobile performance and fast viewport paint times.

2. 🔐 Cybersecurity Engineering & Hardening
•	Zero-Password Cryptographic Authentication: Enforced strict Ed25519 SSH key pair generation for server access, eliminating password-based brute-force attack vectors on port 22.
•	Repository Isolation & Threat Mitigation: Configured private GitHub repository linkages using authenticated SSH deployment tokens to prevent unauthorized source code access or exposure of sensitive configurations.
•	Least Privilege Principle (PoLP): Configured strict Linux directory permissions (755 for directories, 644 for files) across web root directories (public_html / project folders) to prevent unauthorized file execution or cross-site scripting (XSS) payload drops.
•	In-Transit Encryption (TLS/SSL): Enforced HTTPS redirection and strong cipher suites across web server endpoints to protect transaction data and media transfers.

3. ☁️ Cloud Security & Infrastructure Management
•	Cloud Hosting Administration: Managed live cloud deployment on Linux infrastructure using cPanel/WHM environments, ensuring isolated process execution (highcliq execution sandbox).
•	Git-Driven Automated CI/CD Workflows:
o	Initialized local version control inside the cPanel environment.
o	Standardized main branch tracking (main -> origin/main).
o	Automated push-to-deploy workflows directly from cPanel terminal environments to GitHub remote repositories.
•	Storage & Operational Monitoring: Monitored web server storage footprints, tracking build objects (88+ compressed project objects committed via delta compression) and maintaining real-time operational status via Git working tree audits (git status).
